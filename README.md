# ЭксТехСервис — Concept 02 «Cinema»

Одностраничный лендинг сервиса ремонта спецтехники (Сыктывкар): кинематографичный премиум: полноэкранные фото, стекло, тёплый оранжевый акцент и интерактивная схема узлов экскаватора.

**Как открыть:** откройте `index.html` в браузере или запустите любой статический сервер в этой папке. Сборка не нужна; для GitHub Pages / Netlify подходит как есть.

- Стек: HTML, CSS, JS; анимации — [Motion](https://motion.dev) с CDN (без него сайт тоже работает).
- Контакты клиента: объект `CONTACTS` в начале `assets/main.js`.
- Фото: Unsplash (Unsplash License), иллюстративные. Шрифты: Google Fonts (OFL).
- Форма демонстрационная: данные никуда не отправляются.
